# FR24 Georeferenced Polygon Drawer

Real-time georeferenced SVG polygon overlay on Flightradar24 with fixed viewport sync and robust coordinate extraction.

## Features
- Real-time SVG polygon overlay directly on top of the FR24 map engine.
- Flexible coordinate parsing supporting both **DMS** (e.g., `21° 36' 15" N, 87° 28' 34" E`) and **DD** formats.
- Viewport synchronization supporting Mapbox GL, Leaflet, and standard FR24 map instances.

## Installation
1. Install the [Tampermonkey extension](https://www.tampermonkey.net/) in your web browser.
2. Open your `fr24-polygon-drawer.user.js` file in this repository and click **Raw** to trigger direct installation.
